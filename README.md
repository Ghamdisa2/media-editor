# Media Editor

Video / Image / Audio tools. Arabic + English. Android + Windows.

## Build (no install needed): GitHub Actions
1. Create a free GitHub account, then a new repository (name: media-editor).
2. Upload ALL files of this folder to the repository (keep the .github folder).
3. Open the Actions tab -> "Build Media Editor" -> Run workflow (or it runs on every push).
4. When it finishes (about 5-10 min), open the run and download:
   - MediaEditor-Android-APK  -> app-release.apk (install on the phone)
   - MediaEditor-Windows      -> zip; unzip and run media_editor.exe
